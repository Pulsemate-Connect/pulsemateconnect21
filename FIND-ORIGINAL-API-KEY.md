# 🔍 How to Find Your Original Message Central API Key

## ✅ CONFIRMED: You Successfully Used Message Central Before!

The JWT token in your `.env` was **generated by Message Central**, which proves you once had the correct API key and it worked!

**JWT Decoded:**
```json
{
  "sub": "C-B6442109CBD3438",
  "iat": 1785256917,  ← Issued: January 24, 2027
  "exp": 1942936917   ← Expires: June 16, 2031
}
```

This means someone successfully authenticated with Message Central on **January 24, 2027** and got this 5-year token back.

## 🎯 Where to Find the Original API Key

### Method 1: Message Central Dashboard (MOST LIKELY)

1. **Login to Message Central:**
   ```
   https://cpaas.messagecentral.com
   ```

2. **Navigate to one of these sections:**
   - **"API Keys"** or **"API Credentials"**
   - **"Settings" → "API"**
   - **"Developer" → "Authentication"**
   - **"Account" → "Security"**
   - **"VerifyNow" → "Configuration"**

3. **Look for a field labeled:**
   - "API Key"
   - "Secret Key"
   - "Authentication Key"
   - "Customer Secret"
   - "Password" or "Key"

4. **The correct key should:**
   - ✅ Have **NO periods** (no dots)
   - ✅ Be **pure Base64**: only A-Z, a-z, 0-9, +, /, =
   - ✅ Be **shorter** than 190 characters (typically 40-80)
   - ✅ Be **different** from the JWT you have
   - ✅ Might have a "Copy" or "Show" button

## 🔍 What You're Looking For

### ❌ WRONG (What you currently have):
```
eyJhbGciOiJIUzUxMiJ9.eyJzdWIiOiJDLUI2NDQyMTA5Q0JEMzQzOCIsImlhdCI6MTc4NTI1NjkxNywiZXhwIjoxOTQyOTM2OTE3fQ.SecuHOe9iP1AUpSqsNQu0YocZheNbLgCNM2dPe2NqPn2lOIbYIR8tYuKUlroW7_reGLfXlgTYLloxBbx7WxnAQ
```
- Length: 190 characters
- Contains: **3 periods** (.)
- Type: JWT token (output/result)
- Use: For sending OTP (AFTER auth)

### ✅ CORRECT (What you need to find):
```
Example: c2VjcmV0S2V5MTIzNDU2Nzg5MDEyMzQ1Njc4OTA=
```
- Length: Typically 40-80 characters
- Contains: **NO periods**
- Type: Base64 API key (input)
- Use: For generating auth tokens (BEFORE anything else)

## 📝 Verification

Once you find a potential API key, verify it:

1. **Check format:**
   ```bash
   # Should only have these characters: A-Z, a-z, 0-9, +, /, =
   # Should NOT have: periods, spaces, quotes, special chars
   ```

2. **Test it locally:**
   ```bash
   cd backend
   # Update .env with new key
   node test-messagecentral.js
   ```

3. **Check length:**
   - If it's 190 chars with periods → Still wrong (another JWT)
   - If it's 40-100 chars, no periods → Probably correct!

## 🚀 Next Steps After Finding It

1. **Update local `.env`:**
   ```env
   MESSAGE_CENTRAL_PASSWORD=<your-found-api-key>
   ```

2. **Update Render:**
   - Dashboard → `pulsemate-backend` → Environment
   - Change `MESSAGE_CENTRAL_PASSWORD`
   - Save and wait for redeploy

3. **Test:**
   - Open Android app
   - Click "Send OTP"
   - Should work immediately!

## ⚠️ If You Absolutely Cannot Find It

If the original API key is permanently lost:

**Option 1: Generate New Key (if Message Central supports it)**
1. Login to dashboard
2. Look for "Regenerate API Key" or "Create New Key"
3. This might invalidate old tokens, but you'll get a new key

**Option 2: Create New Account**
1. Sign up for a new Message Central account
2. Get fresh credentials
3. Update your app configuration

**Option 3: Switch SMS Provider**
1. Use a different OTP provider (Twilio, SNS, etc.)
2. Update backend to use new provider
3. Keep Message Central as backup

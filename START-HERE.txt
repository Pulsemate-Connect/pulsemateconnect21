  📱 HOW TO RUN THE PATIENT APP - START HERE
═══════════════════════════════════════════════════════

⚠️  IMPORTANT: Emulator cannot start from command line due to 
    AVD configuration. Use Android Studio instead!

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ METHOD 1: ANDROID STUDIO (Works 100%)

  Step 1: Open Android Studio
  
  Step 2: Click "Tools" in top menu
  
  Step 3: Select "Device Manager"
  
  Step 4: Find "PulseMatePixel35" in the list
  
  Step 5: Click the ▶ (Play/Start) button
  
  Step 6: Wait 30-60 seconds for emulator to boot
          (You'll see Android home screen)
  
  Step 7: Open terminal in project folder and run:
          npm run android
  
  Step 8: Wait 5-10 minutes for first build
          (Subsequent builds are much faster!)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ METHOD 2: USE YOUR PHONE (Easier & Faster!)

  Step 1: Enable Developer Mode on your Android phone
          - Go to Settings → About Phone
          - Find "Build Number"
          - Tap it 7 times rapidly
          - You'll see "You are now a developer!"
  
  Step 2: Enable USB Debugging
          - Go to Settings → Developer Options
          - Turn ON "USB Debugging"
  
  Step 3: Connect phone to computer via USB cable
  
  Step 4: On phone, tap "Allow" when USB Debugging prompt appears
  
  Step 5: In terminal, verify connection:
          adb devices
          (Should show your device)
  
  Step 6: Run the app:
          npm run android
  
  Step 7: App installs and launches on your phone!

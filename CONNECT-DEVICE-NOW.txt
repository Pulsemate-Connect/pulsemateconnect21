───────────────────────────────────────────────────────────────────

🔌 CONNECT YOUR DEVICE (3 minutes):

   STEP 1️⃣  ENABLE USB DEBUGGING ON YOUR PHONE:
   
   1. Open Settings on your Android phone
   2. Go to "About phone"
   3. Tap "Build number" 7 times (enables Developer mode)
   4. Go back to Settings
   5. Open "Developer options"
   6. Enable "USB debugging"
   7. Connect USB cable to your PC

   ─────────────────────────────────────────────────────────────

   STEP 2️⃣  ALLOW USB DEBUGGING:
   
   When you connect the USB cable, your phone will show:
   "Allow USB debugging?"
   
   → Tap "Always allow from this computer"
   → Tap "OK"

   ─────────────────────────────────────────────────────────────

   STEP 3️⃣  VERIFY CONNECTION:
   
   Run this command:
   
   adb devices
   
   You should see your device listed:
   
   List of devices attached
   RF8M12345AB     device
   
   ✅ If you see "device" → Connected successfully!
   ❌ If you see "unauthorized" → Allow USB debugging on phone
   ❌ If you see nothing → Check USB cable and try again

───────────────────────────────────────────────────────────────────

🚀 AFTER DEVICE IS CONNECTED:

   Run this command to build and run the app:
   
   npx expo run:android
   
   This will:
   ✅ Build the app (5 minutes first time)
   ✅ Install on your device
   ✅ Launch automatically
   ✅ Ready to test Firebase Phone Auth!

📋 TROUBLESHOOTING:

   ❌ Device not showing in adb devices:
      → Check USB cable (try different cable/port)
      → Make sure USB debugging is enabled
      → Try "File Transfer" mode (not "Charging only")
      → Restart ADB: adb kill-server && adb start-server

   ❌ Device shows "unauthorized":
      → Disconnect and reconnect USB
      → Allow USB debugging on phone
      → Check "Always allow" checkbox

   ❌ Build takes too long / fails:
      → This is normal for first build (5-10 minutes)
      → If path length error, use EAS instead:
        eas build --platform android --profile development

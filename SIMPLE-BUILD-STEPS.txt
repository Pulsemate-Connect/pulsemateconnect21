================================================================================
SIMPLE BUILD STEPS - Do These in YOUR Terminal
================================================================================

IMPORTANT: I cannot run these commands for you. You must open PowerShell/CMD
and type these commands yourself!

================================================================================
STEP 1: Open Terminal
================================================================================

1. Press: Windows Key + R
2. Type: powershell
3. Press: Enter

================================================================================
STEP 2: Navigate to Project
================================================================================

Copy and paste this:

cd "c:\Users\shubh\Desktop\PulseMate Connect\pulsemateconnect21"

Press Enter

================================================================================
STEP 3: Create New EAS Project (MUST DO FIRST!)
================================================================================

Type:

eas init

Press Enter

You'll see:
? Would you like to create a new project? (Y/n)

Type: y
Press Enter

Wait for project creation...

Should show: ✔ Project created

================================================================================
STEP 4: Generate New Keystore (Easiest Solution)
================================================================================

Since you don't have the old keystore password, create a NEW one:

Type:

eas credentials

Press Enter

Navigate:
1. Select: Android (press Enter)
2. Select: production (arrow down 3x, press Enter)
3. Select: Keystore (press Enter)
4. Select: "Set up a new keystore" (press Enter)
5. Select: "Generate new keystore" (press Enter)

Wait... EAS will generate a new keystore for you!

✔ Done! New keystore created

================================================================================
STEP 5: Build AAB
================================================================================

Type:

eas build --platform android --profile production --clear-cache

Press Enter

Wait ~10 minutes for build to complete

You'll see:
√ Build finished
🤖 Android app: https://expo.dev/artifacts/eas/[hash].aab

Click the link to download AAB

================================================================================
STEP 6: Enable Play App Signing (CRITICAL!)
================================================================================

Since we're using a NEW keystore (different from what Play Store expects),
you MUST enable Play App Signing:

1. Go to: https://play.google.com/console
2. Select: PulseMate Connect
3. Navigate: Setup → App integrity → App signing
4. Click: "Use Play App Signing"
5. Select: "Let Google create and manage my app signing key"
6. Confirm

This tells Google: "I'm using a new upload key, please accept it"

================================================================================
STEP 7: Upload AAB to Play Console
================================================================================

1. Go to: Production → Create new release
2. Upload: The AAB file you downloaded
3. Should be ACCEPTED (because of Play App Signing!)
4. Fill release notes
5. Submit for review

================================================================================
WHY THIS WORKS
================================================================================

The old keystore (SHA-1: 0B:84:89:11...) was in the "pulsemateconnect" account.
You don't have access to that account or the keystore password.

Solution:
1. Create NEW keystore (we just did this)
2. Enable Play App Signing in Play Console
3. Google accepts your NEW keystore as "upload key"
4. Google re-signs app with their key for users
5. Everyone can update the app!

This is actually Google's RECOMMENDED approach!

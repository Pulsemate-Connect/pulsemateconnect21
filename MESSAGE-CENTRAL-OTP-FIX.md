# ✅ Message Central OTP Verification Fixed

**Date:** 2026-08-12 03:02 AM  
**Issue:** Real Message Central OTP showing "Invalid OTP" even though SMS received  
**Status:** ✅ FIXED - Now uses Message Central's validation API

---

## Problem

When using real phone numbers (8762697832):
- ✅ SMS with OTP received successfully
- ❌ Entering the OTP showed "Invalid OTP"
- ❌ Backend was trying to verify OTP using bcrypt hash comparison

### Root Cause

The code was trying to:
1. Get OTP from Message Central send response (doesn't exist!)
2. Hash it with bcrypt
3. Store the hash
4. Compare user's OTP against the hash

**But:** Message Central **doesn't return the OTP** - it only sends it via SMS!

---

## Solution

Updated to use Message Central's proper flow:

### Correct Flow

1. **Send OTP:**
   - Call `messageCentralService.sendOTP(phone, 6)`
   - Returns: `{ verificationId, timeout, mobileNumber }`
   - Store `verificationId` in database (NOT the OTP)

2. **Verify OTP:**
   - User enters OTP from SMS
   - Call `messageCentralService.validateOTP(verificationId, userOTP)`
   - Message Central validates the OTP
   - Returns: `{ success: true, verificationStatus: 'VERIFICATION_COMPLETED' }`

### Code Changes

#### sendOtpHandler (Store verificationId)
**Before:**
```javascript
// ❌ WRONG: Trying to hash OTP that doesn't exist
otpHash: await hashPassword(result.otp || ''), 
```

**After:**
```javascript
// ✅ CORRECT: Store verificationId from Message Central
otpHash: result.verificationId, // Store verificationId (NOT the OTP itself)
```

#### verifyOtpHandler (Use Message Central API)
**Before:**
```javascript
// ❌ WRONG: Trying to compare OTP with hash
const isValid = await verifyPassword(cleanOtp, otpRecord.otpHash);
```

**After:**
```javascript
// ✅ CORRECT: Verify with Message Central API
if (isTestNumber) {
  // Test numbers: use hash comparison (test OTP is known)
  isValid = await verifyPassword(cleanOtp, otpRecord.otpHash);
} else {
  // Real numbers: use Message Central API
  const verificationId = otpRecord.otpHash; // Retrieved from DB
  const result = await messageCentralService.validateOTP(verificationId, cleanOtp);
  isValid = result.success && result.verificationStatus === 'VERIFICATION_COMPLETED';
}
```

## Error Handling

Message Central returns specific error codes:

| Error Code | Error Message | User Message |
|-----------|---------------|--------------|
| 702 | WRONG_OTP | Invalid OTP. X attempts remaining. |
| 705 | OTP_EXPIRED | OTP has expired. Please request a new one. |
| 703 | ALREADY_VERIFIED | This OTP has already been used. |
| 505 | INVALID_VERIFICATION_ID | Invalid or expired verification session. |

---

## Security

- ✅ OTP never stored in database (only verificationId)
- ✅ OTP only known to Message Central and user's phone
- ✅ Each verification ID is single-use
- ✅ OTP expires after 60 seconds (configurable)
- ✅ Max 10 verification attempts per 15 minutes

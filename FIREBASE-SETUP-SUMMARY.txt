📋 QUICK START (Copy & Paste These Commands):

1️⃣  GET SHA CERTIFICATE:
   
   cd android
   ./gradlew signingReport
   
   👆 Copy the SHA-1 and SHA-256 values


2️⃣  ADD TO FIREBASE:

   → Open: https://console.firebase.google.com/project/pulsemateconnect/settings/general
   → Find: Android app (in.pulsemateconnect.patient)
   → Click: "Add fingerprint"
   → Paste: Your SHA-1
   → Click: "Save"
   → Repeat for SHA-256


3️⃣  DOWNLOAD & REPLACE:

   → Click: Settings gear icon ⚙️
   → Click: "Download google-services.json"
   → Save to Downloads
   
   Then run:
   copy C:\Users\shubh\Downloads\google-services.json google-services.json
   copy C:\Users\shubh\Downloads\google-services.json android\app\google-services.json


4️⃣  BUILD WITH EAS:

   eas build --platform android --profile development
   
   👆 Wait 20 minutes for build


5️⃣  TEST ON PHONE:

   → Download APK from: https://expo.dev
   → Install on real Android device
   → Test login with your phone number
   → Should receive SMS via Firebase ✅

────────────────────────────────────────────────────────────────────

⚠️  IMPORTANT NOTES:

   • MUST use real Android device (not emulator)
   • CANNOT use Expo Go (must use EAS build)
   • Need Google Play Services on device
   • Need internet connection for Firebase
   • First SMS may take 30 seconds

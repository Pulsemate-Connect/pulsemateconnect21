  EASY METHOD: Upload via cPanel (RECOMMENDED)
═══════════════════════════════════════════════════════════════════════════

STEP 1: Login to cPanel
   • URL: Usually your-domain.com:2083 or your-domain.com/cpanel
   • Enter your hosting username and password

STEP 2: Open File Manager
   • Click "File Manager" icon in cPanel dashboard
   • You'll see your server files

STEP 3: Navigate to Website Root
   • Click on "public_html" folder (or "www" or "htdocs")
   • This is where your website files live

STEP 4: Delete OLD Files (IMPORTANT!)
   • Select ALL files in public_html (click checkboxes)
   • Click "Delete" button at top
   • Confirm deletion
   • This removes the old blank website files

STEP 5: Upload NEW ZIP File
   • Click "Upload" button at top
   • Click "Select File" button
   • Browse to: C:\Users\shubh\Desktop\PulseMate Connect\pulsemateconnect21\dist-website.zip
   • Select the file and click "Open"
   • Wait for upload to complete (shows 100%)

STEP 6: Extract ZIP File
   • Go back to File Manager (close upload window)
   • You should see "dist-website.zip" in public_html
   • Click on "dist-website.zip" to select it
   • Click "Extract" button at top
   • Click "Extract Files" to confirm
   • Files will extract to public_html folder

STEP 7: Clean Up
   • Delete the ZIP file after extraction
   • Select "dist-website.zip"
   • Click "Delete"

STEP 8: Verify Files
   • Your public_html should now contain:
     ✓ index.html (1.2 KB)
     ✓ favicon.ico (14.5 KB)
     ✓ metadata.json (49 B)
     ✓ assets (folder)
     ✓ _expo (folder)

STEP 9: Test Website
   • Open browser
   • Go to: https://pulsemateconnect.in
   • Press Ctrl+F5 to hard refresh
   • Website should load (no more blank page!)

   • Go to: https://filezilla-project.org/download.php

STEP 2: Get FTP Credentials
   • Login to your hosting control panel
   • Find "FTP Accounts" or "FTP Manager"
   • Note down:

     - Username: Your FTP username
     - Password: Your FTP password
     - Port: 21 (or 22 for SFTP)

STEP 3: Connect to Server
   • Open FileZilla
   • Enter Host, Username, Password, Port at top
   • Click "Quickconnect"
   • You'll see:
     - Left side: Your computer files
     - Right side: Server files

STEP 4: Navigate
   • Left side: Browse to C:\Users\shubh\Desktop\PulseMate Connect\pulsemateconnect21\dist
   • Right side: Navigate to /public_html (or /www or /htdocs)

STEP 5: Delete OLD Files on Server
   • Right side (server): Select ALL files
   • Right-click → Delete
   • Confirm deletion

STEP 6: Upload NEW Files
   • Left side: Go inside the "dist" folder
   • Select ALL files and folders (Ctrl+A)
   • Drag to right side (server)
   • Wait for upload to complete
   • Should upload:
     ✓ index.html
     ✓ favicon.ico
     ✓ metadata.json
     ✓ assets (folder with all contents)
     ✓ _expo (folder with all contents)

STEP 7: Verify and Test
   • Check right side shows all files uploaded
   • Open browser
   • Go to: https://pulsemateconnect.in
   • Hard refresh (Ctrl+F5)

  TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

Problem: Can't login to cPanel
Solution: Contact your hosting provider for:
   • cPanel URL
   • Username and password
   • Or ask them to upload the file for you

Problem: Don't have cPanel
Solution: Use FileZilla method or ask hosting support to:
   • Upload dist-website.zip
   • Extract to website root folder

Problem: Website still blank after upload
Solution:
   1. Hard refresh browser (Ctrl+F5)
   2. Clear browser cache
   3. Check you uploaded to correct folder (public_html not a subfolder)
   4. Verify all files extracted (especially _expo folder)
   5. Check browser console (F12) for errors

Problem: "Permission denied" errors
Solution:
   • Contact hosting support to fix file permissions
   • They should set:
     - Files: 644 (readable)
     - Folders: 755 (executable)

                   METHOD 1: AUTO-DEPLOY (RECOMMENDED)
═══════════════════════════════════════════════════════════════════════════════

STEP 1: GET YOUR FTP CREDENTIALS
─────────────────────────────────────────────────────────────────────────────

You need 3 pieces of information from your hosting provider:

  ┌─────────────────────────────────────────────────────────────────────────┐
  │ 1. FTP_SERVER    = ftp.pulsemateconnect.in  (or similar)               │
  │ 2. FTP_USERNAME  = your_username                                        │
  │ 3. FTP_PASSWORD  = your_password                                        │
  └─────────────────────────────────────────────────────────────────────────┘

WHERE TO FIND THESE? (Choose ONE method below)

  ✅ Option A: Check Your Email (FASTEST)
     ────────────────────────────────────────────────────────────────────
     1. Open your email
     2. Search for: "pulsemateconnect" OR "hosting" OR "welcome"
     3. Look for email from your hosting provider (Hostinger, GoDaddy, etc.)
     4. Find section with "FTP Details" or "Account Information"
     5. Copy the FTP server, username, and password
  
  ✅ Option B: Login to cPanel (EASY TO RESET PASSWORD)
     ────────────────────────────────────────────────────────────────────
     1. Open browser and go to: https://pulsemateconnect.in:2083
        (or check your hosting welcome email for cPanel URL)
     
     2. Login with your cPanel username and password
     
     3. Look for "Files" section, click "FTP Accounts"
     
     4. You'll see:
        • FTP Server: Usually shown at top (e.g., ftp.pulsemateconnect.in)
        • Username: Listed in table
        • Password: Click "Change Password" to reset it
     
     5. If you need to reset password:
        a) Click "Change Password" next to your account
        b) Enter a new password (write it down!)
        c) Click "Change Password" button
        d) SAVE this password - you'll need it for GitHub!
  
  ✅ Option C: Contact Hosting Support (THEY WILL HELP!)
     ────────────────────────────────────────────────────────────────────
     1. Go to your hosting provider's website
     
     2. Click "Live Chat" or "Support" button (usually bottom-right)
     
     3. Say: "Hi, I need FTP credentials for pulsemateconnect.in"
     
     4. They will provide:
        • FTP server address
        • FTP username
        • Reset your FTP password
     
     5. Copy and save these credentials!

  ✅ Option D: Check Hosting Dashboard
     ────────────────────────────────────────────────────────────────────
     Hostinger: https://hpanel.hostinger.com → Files → FTP Accounts
     GoDaddy:   https://account.godaddy.com → My Products → Hosting → FTP
     Bluehost:  https://my.bluehost.com → Advanced → FTP Accounts


STEP 2: ADD CREDENTIALS TO GITHUB
─────────────────────────────────────────────────────────────────────────────

Now that you have your FTP credentials, add them to GitHub:

  1. Open this link in your browser:
     https://github.com/Pulsemate-Connect/pulsemateconnect21/settings/secrets/actions
  
  2. Click "New repository secret" button
  
  3. Add Secret #1:
     ┌──────────────────────────────────────────────────────────────────┐
     │ Name:   FTP_SERVER                                               │
     │ Secret: ftp.pulsemateconnect.in  (paste your FTP server here)    │
     └──────────────────────────────────────────────────────────────────┘
     Click "Add secret"
  
  4. Click "New repository secret" button again
  
  5. Add Secret #2:
     ┌──────────────────────────────────────────────────────────────────┐
     │ Name:   FTP_USERNAME                                             │
     │ Secret: your_username  (paste your FTP username here)            │
     └──────────────────────────────────────────────────────────────────┘
     Click "Add secret"
  
  6. Click "New repository secret" button again
  
  7. Add Secret #3:
     ┌──────────────────────────────────────────────────────────────────┐
     │ Name:   FTP_PASSWORD                                             │
     │ Secret: your_password  (paste your FTP password here)            │
     └──────────────────────────────────────────────────────────────────┘
     Click "Add secret"
  
  ✅ You should now see 3 secrets listed:
     • FTP_SERVER
     • FTP_USERNAME
     • FTP_PASSWORD


STEP 3: RUN AUTO-DEPLOY WORKFLOW
─────────────────────────────────────────────────────────────────────────────

  1. Open this link:
     https://github.com/Pulsemate-Connect/pulsemateconnect21/actions
  
  2. On the left side, click "Deploy Website to Server"
  
  3. On the right side, click "Run workflow" button (gray button)
  
  4. A dropdown will appear, click "Run workflow" button again (green button)
  
  5. Wait 3-5 minutes while GitHub:
     ✓ Builds your website
     ✓ Uploads to your server
     ✓ Updates pulsemateconnect.in
  
  6. You'll see a green checkmark when done!


STEP 4: TEST YOUR WEBSITE
─────────────────────────────────────────────────────────────────────────────

  1. Open browser
  
  2. Go to: https://pulsemateconnect.in
  
  3. Press Ctrl + Shift + R (hard refresh to clear cache)
  
  4. Website should now show:
     ✅ Location picker
     ✅ Search bar
     ✅ Doctor listings
     ✅ No more blank white page!

                   METHOD 2: MANUAL UPLOAD (QUICK FIX)
═══════════════════════════════════════════════════════════════════════════════

If you want a quick fix without setting up auto-deploy:


STEP 1: LOGIN TO CPANEL
─────────────────────────────────────────────────────────────────────────────

  1. Open browser
  
  2. Go to: https://pulsemateconnect.in:2083
     (or your cPanel URL from hosting provider)
  
  3. Login with your cPanel username and password


STEP 2: OPEN FILE MANAGER
─────────────────────────────────────────────────────────────────────────────

  1. In cPanel dashboard, look for "Files" section
  
  2. Click "File Manager" icon
  
  3. Navigate to "public_html" folder (double-click to open)


STEP 3: DELETE OLD FILES
─────────────────────────────────────────────────────────────────────────────

  1. In public_html folder, you'll see old website files
  
  2. Select ALL files and folders (click checkbox at top)
  
  3. Click "Delete" button at the top
  
  4. Confirm deletion
  
  5. The public_html folder should now be EMPTY


STEP 4: UPLOAD NEW WEBSITE
─────────────────────────────────────────────────────────────────────────────

  1. In File Manager, click "Upload" button at the top
  
  2. Click "Select File" button
  
  3. Navigate to: C:\Users\shubh\Desktop\PulseMate Connect\pulsemateconnect21
  
  4. Select file: dist-website.zip (2.8 MB file)
  
  5. Click "Open" to start upload
  
  6. Wait for upload to complete (100%)
  
  7. Click "Go Back to..." link to return to File Manager


STEP 5: EXTRACT ZIP FILE
─────────────────────────────────────────────────────────────────────────────

  1. In public_html folder, you should see "dist-website.zip"
  
  2. Right-click on "dist-website.zip"
  
  3. Click "Extract"
  
  4. Confirm extraction
  
  5. Wait for extraction to complete
  
  6. You should now see these files in public_html:
     ✓ index.html
     ✓ favicon.ico
     ✓ metadata.json
     ✓ assets/ (folder)
     ✓ _expo/ (folder)


STEP 6: DELETE ZIP FILE (OPTIONAL CLEANUP)
─────────────────────────────────────────────────────────────────────────────

  1. Select "dist-website.zip" file
  
  2. Click "Delete" button
  
  3. Confirm deletion


STEP 7: TEST YOUR WEBSITE
─────────────────────────────────────────────────────────────────────────────

  1. Open browser
  
  2. Go to: https://pulsemateconnect.in
  
  3. Press Ctrl + Shift + R (hard refresh to clear cache)
  
  4. Website should now show:
     ✅ Location picker
     ✅ Search bar
     ✅ Doctor listings
     ✅ No more blank white page!

                          🆘 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

ISSUE: "I don't know my hosting provider"
─────────────────────────────────────────────────────────────────────────────
  • Check your email for "pulsemateconnect" - look for invoices
  • Check your bank statements for recurring hosting charges
  • Go to https://who.is and search "pulsemateconnect.in" to see registrar


ISSUE: "I can't find my FTP credentials"
─────────────────────────────────────────────────────────────────────────────
  • Search email for: "hosting" OR "welcome" OR "cpanel"
  • Login to cPanel and reset password in FTP Accounts
  • Contact hosting support via live chat (fastest!)


ISSUE: "I can't login to cPanel"
─────────────────────────────────────────────────────────────────────────────
  • Try: https://pulsemateconnect.in:2083
  • Try: https://pulsemateconnect.in/cpanel
  • Check hosting welcome email for cPanel URL
  • Contact hosting support to reset cPanel password


ISSUE: "GitHub Secrets page says 'Access Denied'"
─────────────────────────────────────────────────────────────────────────────
  • Make sure you're logged into GitHub
  • Make sure you have admin/owner access to the repository
  • Try this link: https://github.com/Pulsemate-Connect/pulsemateconnect21/settings


ISSUE: "Auto-deploy workflow failed"
─────────────────────────────────────────────────────────────────────────────
  • Check if FTP credentials are correct
  • Try testing FTP with FileZilla first
  • Check GitHub Actions logs for error details
  • Try manual upload method instead (Method 2)


ISSUE: "Website still shows blank page after upload"
─────────────────────────────────────────────────────────────────────────────
  • Clear browser cache (Ctrl + Shift + Delete)
  • Try hard refresh (Ctrl + Shift + R)
  • Try different browser
  • Check browser console (F12) for errors
  • Verify all files were uploaded to public_html (not a subfolder!)


ISSUE: "Upload is too slow in cPanel"
─────────────────────────────────────────────────────────────────────────────
  • File is only 2.8 MB, should take 1-2 minutes max
  • Check your internet connection
  • Try using FileZilla instead (faster for large uploads)
  • Contact hosting support if cPanel upload keeps timing out

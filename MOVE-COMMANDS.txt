============================================================
MANUAL MOVE COMMANDS (Copy & Paste to PowerShell)
============================================================

STEP 1: Create destination folder
----------------------------------
mkdir C:\pm

STEP 2: Copy project (2-3 minutes)
-----------------------------------
Copy-Item -Path "C:\Users\shubh\Desktop\PulseMate Connect\pulsemateconnect21" -Destination "C:\pm\pulsemateconnect21" -Recurse -Force

STEP 3: Verify copy succeeded
------------------------------
Test-Path "C:\pm\pulsemateconnect21\package.json"

(Should output: True)

STEP 4: Close VS Code and open from new location
-------------------------------------------------
code C:\pm\pulsemateconnect21

STEP 5: In new VS Code terminal, rebuild
-----------------------------------------
cd C:\pm\pulsemateconnect21\android
.\gradlew clean
.\gradlew assembleRelease

STEP 6: After successful build, find APK at:
---------------------------------------------
C:\pm\pulsemateconnect21\android\app\build\outputs\apk\release\app-release.apk

STEP 7: Install APK
--------------------
adb install C:\pm\pulsemateconnect21\android\app\build\outputs\apk\release\app-release.apk

STEP 8: Clean up old folder (AFTER VERIFYING NEW LOCATION WORKS)
-----------------------------------------------------------------
Remove-Item -Path "C:\Users\shubh\Desktop\PulseMate Connect\pulsemateconnect21" -Recurse -Force

============================================================
ALTERNATIVE: Use robocopy (faster, more reliable)
============================================================

robocopy "C:\Users\shubh\Desktop\PulseMate Connect\pulsemateconnect21" "C:\pm\pulsemateconnect21" /E /Z /MT:16 /R:3 /W:5

(Explanation: /E = all subdirs, /Z = restartable mode, /MT:16 = 16 threads, /R:3 = 3 retries, /W:5 = 5 sec wait)

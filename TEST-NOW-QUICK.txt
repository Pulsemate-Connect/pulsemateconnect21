💡 WHAT WAS FIXED:

Frontend was calling storeLogin({ user, token }) but the auth store didn't 
have a 'login' function - it only had 'setAuth'. This caused an error that
was caught and displayed as "Invalid OTP".

Now the auth store has both:
- setAuth(user, accessToken) - original function
- login({ user, token }) - new alias for clinic auth modal

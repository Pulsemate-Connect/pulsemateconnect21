┌────────────────────────────────────────────────────────┐
│  STEP 1: OPEN ANDROID STUDIO                           │
└────────────────────────────────────────────────────────┘

  Windows Start Menu  →  Search "Android Studio"  →  Open

  [🪟 Start] → [🔍 Android Studio] → [📱 Android Studio]


┌────────────────────────────────────────────────────────┐
│  STEP 2: OPEN DEVICE MANAGER                           │
└────────────────────────────────────────────────────────┘

  In Android Studio window:

  ┌─────────────────────────────────────────┐
  │ File  Edit  View  Navigate  Code  ...  │
  │ ↓                                       │
  │ Tools  ←─── CLICK HERE                 │
  │   ├─ Device Manager  ←─── THEN CLICK   │
  │   ├─ SDK Manager                        │
  │   └─ ...                                │
  └─────────────────────────────────────────┘


┌────────────────────────────────────────────────────────┐
│  STEP 3: START EMULATOR                                │
└────────────────────────────────────────────────────────┘

  Device Manager panel will open on right side:

  ┌─────────────────────────────────────────┐
  │ Device Manager                          │
  ├─────────────────────────────────────────┤
  │                                         │
  │  📱 PulseMatePixel35        [▶] ←─ CLICK│
  │     Pixel 5                             │
  │     API 35                              │
  │                                         │
  │  📱 PulseMatePixel35c       [▶]        │
  │     Pixel 5                             │
  │     API 35                              │
  │                                         │
  └─────────────────────────────────────────┘


┌────────────────────────────────────────────────────────┐
│  STEP 4: WAIT FOR EMULATOR TO BOOT                     │
└────────────────────────────────────────────────────────┘

  A new window will appear:

  ┌──────────────────────┐
  │                      │  ← Emulator window
  │                      │
  │    Loading...        │
  │         ⏳           │
  │                      │
  │  Android booting...  │
  │                      │
  └──────────────────────┘

  Wait 30-60 seconds until you see:

  ┌──────────────────────┐
  │  🕐 12:00            │
  │                      │
  │       [🔍]          │  ← Home screen!
  │                      │
  │  [📞] [📷] [🌐] [✉] │
  │                      │
  └──────────────────────┘


┌────────────────────────────────────────────────────────┐
│  STEP 5: RUN THE APP                                   │

  C:\...\pulsemateconnect21> npm run android

  You'll see:
    ✓ Metro bundler starting...
    ✓ Building Android app...
    ✓ Installing on emulator...
    ✓ Launching app...

STEP 1: Open Terminal/PowerShell

Press: Windows Key + R

================================================================================
STEP 2: Navigate to Project
================================================================================

Copy-paste this command:

cd "c:\Users\shubh\Desktop\PulseMate Connect\pulsemateconnect21"

================================================================================
STEP 3: Run EAS Credentials
================================================================================

Copy-paste this command:

eas credentials

Press: Enter

================================================================================
STEP 4: Interactive Menu - Select Platform
================================================================================

You'll see:
? Select platform »
  > Android
    iOS
    Exit

ACTION: Press Enter (Android is already selected)

================================================================================
STEP 5: Interactive Menu - Select Build Profile
================================================================================

You'll see:
? Which build profile do you want to configure? »
    development
    preview
    apk
    production

ACTION: 
  1. Press Down Arrow 3 times to highlight "production"
  2. Press Enter

================================================================================
STEP 6: Interactive Menu - Select Keystore
================================================================================

You'll see:
What do you want to do? »
  > Keystore
    Google Service Account Key
    FCM Server Key
    Go back

ACTION: Press Enter (Keystore is already selected)

================================================================================
STEP 7: Keystore Menu - Use Different Keystore
================================================================================

You'll see:
? Keystore »
    View credentials
    Set up a new keystore
    Use a different Keystore
    Remove Keystore
    Go back

ACTION:
  1. Press Down Arrow 2 times to highlight "Use a different Keystore"
  2. Press Enter

================================================================================

  1. Make sure "Keystore yKf5TaJ1Kx" is highlighted (should be at top)

STEP 9: Confirmation
================================================================================

You'll see:
✔ Selected Keystore: yKf5TaJ1Kx

STEP 10: Verify Change (Optional but Recommended)
================================================================================

You'll be back at keystore menu:
? Keystore »
  > View credentials
    Set up a new keystore
    Use a different Keystore
    Remove Keystore
    Go back

ACTION:
  1. Press Enter (View credentials)
  2. Check it shows:
     Keystore Credentials yKf5TaJ1Kx
     SHA1 Fingerprint: 0B:84:89:11:44:B1:B8:DB:C4:9B:4D:05:ED:AA:83:77:0F:30:43:4F

  3. Press any key to continue

================================================================================
STEP 11: Exit
================================================================================

ACTION:
  1. Press Down Arrow to highlight "Go back"
  2. Press Enter
  3. Repeat until you see "✔ All done!" or back at terminal prompt

================================================================================
STEP 12: Build AAB
================================================================================

Now run the build command:

eas build --platform android --profile production --clear-cache

WATCH FOR THIS LINE in the first 30 seconds:
√ Using Keystore from configuration: Build Credentials yKf5TaJ1Kx (default)

IF YOU SEE yKf5TaJ1Kx:
  ✅ Perfect! Let build continue (takes ~10 minutes)

IF YOU SEE 8Xpt79mt7A:
  ❌ Press Ctrl+C immediately
  ❌ Something went wrong - repeat steps above

================================================================================
STEP 13: After Build Completes
================================================================================

You'll see:
√ Build finished
🤖 Android app:
https://expo.dev/artifacts/eas/[some-hash].aab

ACTION:
  1. Click the link to download AAB
  2. Save as: pulsemateconnect-v1.3.7-build-81.aab
  3. Upload to Google Play Console
